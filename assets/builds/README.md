# Imágenes de builds

Cada build puede definir `imagePath` en `config/builds.json`. El botón **Ver Build** adjunta el archivo indicado y lo muestra en una respuesta efímera.

La imagen inicial incluida es:

- `05-bear-paws-x2.webp`: imagen original entregada para Bear Paws (x2).

No se generan imágenes desde el bot. Los archivos deben ser PNG/JPG/WebP válidos y mantenerse por debajo del límite de adjuntos de Discord del servidor.
